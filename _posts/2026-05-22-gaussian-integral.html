The Gaussian Integral

One of the most beautiful results in all of mathematics — a complete guide from proof to code.

$$\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}$$

§ 01

What Is the Gaussian Integral?

At its heart, the Gaussian integral asks a single question: what is the area under the bell curve $e^{-x^2}$ from $-\infty$ to $+\infty$?

The function $f(x) = e^{-x^2}$ has no elementary antiderivative — you cannot write a closed-form expression for $\int e^{-x^2}\,dx$ in terms of familiar functions. Yet the definite integral over all of $\mathbb{R}$ has the stunningly clean value $\sqrt{\pi}$. This apparent miracle is why mathematicians have been enchanted by it for nearly three centuries.

🗓️ Historical note

The result is attributed to Carl Friedrich Gauss (1777–1855), who used it in his work on the normal distribution. The method we present — squaring the integral and switching to polar coordinates — appears to have been first published by Poisson in 1823.

The function is symmetric ($e^{-x^2} = e^{-(-x)^2}$), always positive, and decays rapidly to zero as $|x| \to \infty$. These properties guarantee the integral converges.

§ 02

The Polar Coordinates Proof

The standard proof is one of the most elegant tricks in analysis. We cannot integrate the Gaussian directly — so instead, we square it and convert to polar coordinates.

1

Define $I$

Let $I$ be the integral we want to evaluate:

Definition

$$I = \int_{-\infty}^{\infty} e^{-x^2}\,dx$$

2

Compute $I^2$

Write $I^2$ as a product of two independent integrals (using a dummy variable $y$):

Key Insight

$$I^2 = \left(\int_{-\infty}^{\infty} e^{-x^2}\,dx\right)\left(\int_{-\infty}^{\infty} e^{-y^2}\,dy\right) = \int_{-\infty}^{\infty}\int_{-\infty}^{\infty} e^{-(x^2+y^2)}\,dx\,dy$$

This is now a double integral over the entire plane.

3

Switch to Polar Coordinates

The integrand $e^{-(x^2+y^2)}$ depends only on $r^2 = x^2 + y^2$ — it has perfect circular symmetry. This calls for polar coordinates:

Substitution

$$x = r\cos\theta,\quad y = r\sin\theta,\quad dx\,dy = r\,dr\,d\theta$$

The Cartesian plane maps to $r \in [0, \infty)$ and $\theta \in [0, 2\pi)$.

4

Evaluate the Double Integral

Evaluation

$$I^2 = \int_0^{2\pi}\int_0^{\infty} e^{-r^2}\,r\,dr\,d\theta$$ $$= 2\pi \int_0^{\infty} r\,e^{-r^2}\,dr$$

Now substitute $u = r^2$, so $du = 2r\,dr$:

u-substitution

$$I^2 = 2\pi \cdot \frac{1}{2}\int_0^{\infty} e^{-u}\,du = \pi \Big[-e^{-u}\Big]_0^{\infty} = \pi(0 - (-1)) = \pi$$

5

Take the Square Root

Since $I > 0$ (the integrand is positive), we take the positive square root:

The Gaussian Integral

$$I^2 = \pi \implies I = \sqrt{\pi}$$

✦ Why does the trick work?

The key insight is that $e^{-r^2}$ is radially symmetric — it only depends on the distance from the origin. By squaring $I$, we create a 2D integral with this symmetry, making polar coordinates the natural choice. The factor $r$ in the Jacobian $r\,dr\,d\theta$ is what makes $\int_0^\infty r\,e^{-r^2}\,dr$ tractable via simple substitution.

The 3D Perspective

To understand the polar-coordinates proof geometrically: the product $I^2$ represents the volume under the surface $z = e^{-(x^2+y^2)}$ over the entire plane. This bell-shaped mound has volume $\pi$, so each "slice" through its cross-section gives area $\sqrt{\pi}$.

Polar decomposition of $I^2$: integrand as a function of $r$

$r\,e^{-r^2}$ — the radial integrand. Area under this curve = $\tfrac{1}{2}$, so $I^2 = 2\pi \cdot \tfrac{1}{2} = \pi$

§ 04

Solving with Python

Python offers several distinct approaches: symbolic computation, numerical quadrature, Monte Carlo estimation, and direct use of the special-functions library. Let's explore each.

1. Symbolic Computation with SymPy

Python · SymPy 
from sympy import *

x = symbols('x')

# Define the integrand
integrand = exp(-x**2)

# Compute the definite integral symbolically
result = integrate(integrand, (x, -oo, oo))

print(f"Gaussian integral = {result}")
# Output: Gaussian integral = sqrt(pi)

print(f"Numerical value  = {float(result):.8f}")
# Output: Numerical value  = 1.77245385

# Also compute the general form ∫ e^(-a*x²) dx
a = symbols('a', positive=True)
general = integrate(exp(-a*x**2), (x, -oo, oo))
print(f"General form     = {general}")
# Output: General form     = sqrt(pi)/sqrt(a)

2. Numerical Quadrature with SciPy

Python · SciPy 
import numpy as np
from scipy import integrate
import math

# Method 1: quad (adaptive Gaussian quadrature)
result, error = integrate.quad(
    lambda x: np.exp(-x**2),
    -np.inf, np.inf
)
print(f"quad result  : {result:.10f}")
print(f"error bound  : {error:.2e}")
print(f"sqrt(pi)     : {math.sqrt(math.pi):.10f}")

# Method 2: Riemann sum (manual, educational)
def riemann_gaussian(n=10000, L=10):
    x = np.linspace(-L, L, n)
    dx = x[1] - x[0]
    return np.sum(np.exp(-x**2)) * dx

print(f"Riemann (n=10000): {riemann_gaussian():.10f}")

3. Monte Carlo Estimation

Monte Carlo methods use random sampling to estimate integrals. For the Gaussian, we can use the fact that sampling from the standard normal distribution is equivalent to computing the integral.

Python · Monte Carlo 
import numpy as np

def monte_carlo_gaussian(N=10_000_000, L=5):
    """
    Estimate ∫_{-L}^{L} e^{-x²} dx via Monte Carlo.
    Sample x ~ Uniform(-L, L), then:
        integral ≈ (2L) · E[e^{-x²}]
    """
    x = np.random.uniform(-L, L, N)
    estimate = 2*L * np.mean(np.exp(-x**2))
    return estimate

np.random.seed(42)
estimate = monte_carlo_gaussian()
print(f"Monte Carlo (N=10M): {estimate:.6f}")
print(f"True value √π     : {np.sqrt(np.pi):.6f}")

# Convergence study
print("\nConvergence as N grows:")
for N in [100, 1000, 10000, 100000, 1000000]:
    est = monte_carlo_gaussian(N)
    err = abs(est - np.sqrt(np.pi))
    print(f"  N={N:>8,}: {est:.5f}  (error {err:.2e})")

4. Using the Error Function (erf)

Python · Special Functions 
from scipy.special import erf, erfinv
import numpy as np

# The error function is defined as:
# erf(x) = (2/√π) ∫₀ˣ e^{-t²} dt
# So: ∫_{-∞}^{∞} e^{-t²} dt = √π · erf(∞) = √π · 1 = √π

# Definite integral from 0 to x:
def gaussian_partial(x):
    """∫_{-x}^{x} e^{-t²} dt"""
    return np.sqrt(np.pi) * erf(x)

for x_val in [1, 2, 3, 5, np.inf]:
    val = gaussian_partial(x_val)
    pct = 100 * val / np.sqrt(np.pi)
    print(f"  ∫_{{-{x_val}}}^{{{x_val}}} = {val:.5f}  ({pct:.2f}% of √π)")

✦ Which method to use?

Use SymPy when you need exact symbolic answers. Use scipy.integrate.quad for fast, accurate numerics. Use Monte Carlo to demonstrate convergence or for high-dimensional generalizations. Use erf for computing probabilities under the normal distribution.

§ 05

Important Variants

The Gaussian integral has several important generalizations, each with elegant closed forms.

Scaled Gaussian

General Parameter

$$\int_{-\infty}^{\infty} e^{-ax^2}\,dx = \sqrt{\frac{\pi}{a}}, \qquad a > 0$$

With Linear Term (Completing the Square)

Linear Exponent

$$\int_{-\infty}^{\infty} e^{-ax^2 + bx}\,dx = \sqrt{\frac{\pi}{a}}\,e^{b^2/4a}$$

Proof: complete the square in the exponent: $-ax^2 + bx = -a(x - b/2a)^2 + b^2/4a$, shift $u = x - b/2a$, and the Jacobian is 1.

With Polynomial (Gaussian Moments)

Even Powers

$$\int_{-\infty}^{\infty} x^{2n} e^{-x^2}\,dx = \frac{(2n)!}{4^n\,n!}\,\sqrt{\pi}$$

Odd powers integrate to zero by symmetry (odd integrand over symmetric interval).

Half-Line Integral

Half Gaussian

$$\int_0^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}$$

Connection to the Gamma Function

Gamma Connection

$$\int_0^{\infty} e^{-x^2}\,dx = \frac{1}{2}\,\Gamma\!\left(\frac{1}{2}\right), \qquad \Gamma\!\left(\frac{1}{2}\right) = \sqrt{\pi}$$

More generally: $\int_0^\infty x^{n-1}e^{-x^2}\,dx = \tfrac{1}{2}\,\Gamma(n/2)$. This connects the Gaussian integral to the entire family of Gamma integrals.

§ 06

Applications Across Science

The Gaussian integral appears wherever continuous distributions, diffusion, or oscillation arise.

📊

Probability & Statistics

The normal distribution $\mathcal{N}(\mu, \sigma^2)$ normalizes to 1 precisely because $\int e^{-x^2}dx = \sqrt{\pi}$. Every z-table and p-value rests on this.

⚛️

Quantum Mechanics

The harmonic oscillator ground state $\psi_0 \propto e^{-x^2/2}$ is a Gaussian. Computing expectation values requires Gaussian integrals.

🌡️

Heat & Diffusion

The fundamental solution to the heat equation $u_t = u_{xx}$ is a Gaussian. Conservation of energy is verified via the Gaussian integral.

📡

Signal Processing

The Fourier transform of a Gaussian is another Gaussian. This is central to filter design, uncertainty principles, and spectral analysis.

🧲

Statistical Mechanics

Partition functions in the Boltzmann distribution and path integrals in field theory both rely on Gaussian integrals as a foundation.

🤖

Machine Learning

Gaussian processes, variational inference, and the normalization of softmax-like distributions all involve evaluating or approximating Gaussian integrals.

§ 07

Extra Ideas to Explore

1. The Fresnel Integrals

If you replace $e^{-x^2}$ with $e^{ix^2}$ (a complex Gaussian), you get the Fresnel integrals $\int_0^\infty \cos(x^2)dx = \int_0^\infty \sin(x^2)dx = \tfrac{\sqrt{2\pi}}{4}$. These appear in optics and diffraction theory.

2. Multidimensional Gaussian

n-Dimensional

$$\int_{\mathbb{R}^n} e^{-\mathbf{x}^T\mathbf{A}\mathbf{x}}\,d^n\mathbf{x} = \frac{\pi^{n/2}}{\sqrt{\det \mathbf{A}}}$$

This $n$-dimensional generalization, where $\mathbf{A}$ is a positive-definite matrix, is the backbone of multivariate statistics and Gaussian processes.

3. Stirling's Approximation via Gaussians

Stirling's famous formula $n! \approx \sqrt{2\pi n}\,(n/e)^n$ can be derived by approximating the Gamma function $\Gamma(n+1)$ with a Gaussian near its peak — a technique called the Laplace method or saddle-point approximation.

4. Path Integrals in Physics

Feynman's path integral formulation of quantum mechanics integrates over all possible particle trajectories. For the harmonic oscillator, this reduces to an infinite-dimensional Gaussian integral — the most beautiful generalization of the result we proved.

5. The Wallis Product Connection

Combining the Gaussian integral with the reflection formula $\Gamma(z)\Gamma(1-z) = \pi/\sin(\pi z)$ at $z = 1/2$ gives $[\Gamma(1/2)]^2 = \pi$, and this is connected to the Wallis product for $\pi$.

⚡ Challenge problems

Try to prove: (1) $\int_{-\infty}^\infty x^2 e^{-x^2}dx = \sqrt{\pi}/2$ using integration by parts. (2) The Fourier transform $\hat{f}(\xi) = \int e^{-x^2}e^{-2\pi i x\xi}dx = \sqrt{\pi}\,e^{-\pi^2\xi^2}$ (another Gaussian!). (3) Generalize the polar proof to $n$ dimensions to derive $\int_{\mathbb{R}^n} e^{-|\mathbf{x}|^2}d^n\mathbf{x} = \pi^{n/2}$.
